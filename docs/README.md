# ydst documentation

This directory contains the primary documentation for **ydst** (YAML data-structure templates).

ydst is a Python library that loads YAML into a **template object graph** (plain Python values + typed template nodes) and renders it into a **concrete Python data structure** (dict/list/scalars) given a runtime context and an optional function registry.
